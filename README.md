# Physician CRM V2 — public privacy and support

Buildless HTML and CSS for the current synthetic beta. Only public website files belong here. Never copy the private application repository, records, keys, signing material or build logs into this repository.

GitHub Pages: deploy main / (root), HTTPS enforced. `.nojekyll` disables Jekyll. There are no dependencies, JavaScript, forms or analytics. Edit the three HTML pages and shared style.css directly; keep the policy and Apple privacy references aligned when data handling changes.
